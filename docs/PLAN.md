# Limitless — Milestones

Each milestone ends with a demo (a short published page with architecture, screenshots and a live
run) before work continues. Self-hosting starts at M2: from then on, features are built *by the
factory* via PRs against `MattFlower/limitless`, reviewed and merged by the orchestrator.

## Now and next

Updated 2026-10-07, from the owner's answers to the M5 status review.

1. **M5.1 Speed, now.** Speed limits how fast everything else gets built, so it comes first. Review
   quality must not drop to get it: a change that touches review or verify is measured on the review
   eval (M5.2) before it lands, and review effort, coverage and models are not traded for time.
2. **Decided and small:** triage runs Codex Luna, then Claude Haiku 5.5 (#410); the machine-named
   implicit provider is removed and LAN llama.cpp hosts come from config (#411).
3. **M5.2 Review parity**, built alongside M5.1 because it is M5.1's guardrail.
4. Finish **M5** and **M5.5**, then **M6** (work-ready).
5. **M6.5 Self-directed delivery**, which builds on M5.2.

M4.6 (spec quality) and M7 (stage craft) are paused.

## Definition of done (from PROMPT.md)
1. The factory has completed tasks end-to-end without errors (tracked in the UI's run history).
2. All eight "Required Functionality" items are shipped and documented.
